# AI対話アプリ V2 要件定義書（docs/ai/v2/requirements.md）

- 根拠：docs/ai/v2/request.md（変更要望と授業の共通条件）
- 作業ブランチ：feature/ai-app-v2

## 1 目的・利用者・開始条件・範囲
- 目的：話題ごとに会話を分け、同じ会話の前のやり取りを踏まえて追加質問でき、再読み込み後も会話を再開できるようにする
- 利用者：単一利用者（授業の受講者本人）。ローカル環境で評価する
- 開始条件：V1 でローカルから実際の Gemini の回答・201・履歴保存を確認済みであること（確認済み）
- 必須（標準）：会話の作成・一覧・切り替え、会話ごとの履歴表示、文脈付きの質問、再読み込み後の再開、入力検証、失敗時の扱い、公開環境での停止、V1・TOP・TODO の維持
- 発展（今回は作らない）：ログイン、ユーザー別の権限管理、会話名の変更・削除、V1 履歴の移行

## 2 必須要件

| ID | WISH | 要件 | 受入条件 | 根拠 |
| --- | --- | --- | --- | --- |
| REQ-V2-01 | WISH-V2-02 | 会話名を入力して新規会話を作成し、一覧から選べる | A・B の 2 件を作成し、一覧から切り替えられる | 要望 |
| REQ-V2-02 | WISH-V2-02・03 | 選択した会話の最新 20 往復を古い順に表示する。空の会話は正常な 0 件。再読み込み後に一覧から開くと履歴を再取得できる | 21 往復以上ある会話で最新 20 往復だけが古い順に出る。空の会話は「まだやり取りがありません」で 200・空配列。再読み込み後に A を選ぶと A の履歴が出る | 共通条件（20 往復） |
| REQ-V2-03 | WISH-V2-01・03 | 同じ会話の保存済み最新 5 往復を古い順に並べ、今回の質問を末尾に加えて Gemini に渡す | A で伝えた架空の合言葉を、A の追加質問で答えられる。A の 2 回目の送信内容が user → model → user になる | 共通条件（5 往復） |
| REQ-V2-04 | WISH-V2-02 | 会話ごとに表示と送信文脈を分け、別の会話の履歴を混ぜない | 新規会話 B に A の履歴が表示されない。B の初回の送信内容が user 1 件だけ。B で A の合言葉を聞いても答えられない | 要望 |
| REQ-V2-05 | WISH-V2-01・共通条件 | 会話名 1〜50、質問 1〜2,000 コードポイント、JSON 16KiB 以内を検証する。不正な会話 ID は 400、存在しない会話は 404 とし、どちらも Gemini を呼ばない。回答取得と保存が完了したときだけ 201。失敗時は成功扱いせず、入力を残し、操作可能に戻す。自動再送しない | 各不正入力で 4xx が返り保存されない。AI 失敗・保存失敗で 201 にならず、画面に質問が残る | 共通条件 |
| REQ-V2-06 | 共通条件 | V1 の画面・API・履歴と TOP・TODO を維持する。公開環境では V2 の API を停止する | V1・TOP・TODO が従来どおり動く。公開環境で V2 の全 API が 503 | 共通条件 |

## 3 非機能要件
| ID | 要件 | 受入条件 |
| --- | --- | --- |
| REQ-V2-N01 | API キー・DB 接続情報はサーバーだけで扱い、ブラウザ・Git・ログに出さない（V1 と同じ） | public/ai/v2 にキーや Gemini の URL がない |
| REQ-V2-N02 | 会話名・質問・回答は文字列として表示し、HTML として実行しない | HTML に見える文字列がそのまま表示される |
| REQ-V2-N03 | SQL はプレースホルダを使い、会話 ID で必ず絞り込む | Model の SQL に値の文字列連結がない |
| REQ-V2-N04 | Gemini の待機 30 秒、SDK 再試行なし、出力 1024 トークン（V1 と同じ） | V1 と同じ設定 |

## 4 データ要件
| ID | 要件 |
| --- | --- |
| REQ-V2-D01 | 会話（ID、会話名、作成日時）と往復（ID、会話 ID、質問、回答、作成日時）を V2 専用テーブルに分けて保存する。往復は会話 ID の外部キーで会話に属する |
| REQ-V2-D02 | 既存テーブル（todo_tasks、v2_todo_tasks、ai_qa_logs）を変更・削除しない |

## 5 画面表示 20 往復と Gemini へ渡す 5 往復の区別
| 用途 | 件数 | 並び | 取得のきっかけ |
| --- | --- | --- | --- |
| 画面の履歴表示 | 最新 20 往復 | 古い順 | 会話の選択時（GET /turns） |
| Gemini へ渡す文脈 | 最新 5 往復 | 古い順＋今回の質問を末尾 | 質問の送信時（POST /turns のサーバー内部） |
